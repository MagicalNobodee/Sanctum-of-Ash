# 减少日常紫晶供给，补足 Boss 血线掉落

关联 Issue #16；负责人 MagicalNobodee · Codex。开始基线 c9de4e10ef97c9cb592209066d592ffb9483ac36，验证前同步至 48dfb549a466dc740a0f64b0bef090ece3a5d587，保留 #15 更新一览与 #17 近战距离调整。

## 改动
- 普通怪能量球概率从 54% 降至 24%，基础能量 11 降至 7；重怪/精英从 82%/16 降至 38%/10。保留原难度与怪群密度修正，平均供给约减少七成。
- 可打碎物件从 26%/10 降至 12%/6；Boss 召唤怪从 88%/15 降至 50%/10。
- Boss 在剩余 75%、50%、25% 生命各一次掉落。以初始护卫及两轮增援（深渊三轮）的预计供给从 240 战斗能量预算中扣除，再施加生命难度修正；补给总基数最低 90，均分三次。单人实际每次 43–63 能量，每批约 7–10 颗球，护卫越少补偿越多。保留击杀 48 与清房直接恢复，替换原半血固定 26。
- 多血线重击和致死伤害补齐尚未触发的奖励，各线只发一次；由主机产生并沿现有消息同步，各玩家独立拾取。未修改联机协议、存档、余烬或回血球。
- 复用护卫数量计算，增援本身不变；新增紫晶专项测试接入平衡套件。校正历史 LAN 测试的旧开局流程、倍率、英文标题、多波清场、护盾伤害及主动退出预期；两浏览器均使用低画质和独立服务端口。波次同步检查等待实际接收完成。
