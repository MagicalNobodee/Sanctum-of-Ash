# 免费异地联机通道与断线恢复

## 改动

- 补齐原来未完成的房间恢复：保存恢复凭据、检测无回应的连接、自动重试，维持玩家身份与原房间；主动离开取消恢复。客户端最长尝试约 40 秒，服务端保留名额 45 秒。
- 直连每个同伴都检查真实回应；假连、协商卡住或拥塞时转发动作，按退避间隔重新协商。瞬时网络波动不立即销毁连接；区分协商批次，先发协商描述再发早到的候选地址。
- 位置与敌人状态可跳过旧包，使用独立的无重传直连通道；重要事件双路投递、确认、补送及去重，避免攻击、救援等重复生效。加入能力标志，旧页面或旧服务不启用不兼容的双路补送。
- 免费入口依次尝试本机 Cloudflare HTTP/2、Serveo、localhost.run；同时验证 HTTPS 返回的是本机游戏、WSS 真能收到欢迎包后才显示可用，持续检查并在失效后轮换。修复旧逻辑超时后重复跳过供应方的问题；缺少 cloudflared 会自动继续尝试。
- 原网址改变时，仍连通的直连可传递新网址。恢复时补回错过的开局/换层资料，相同已加载楼层不会重建。大厅展示真实恢复状态及失败说明。
- 更新浏览器测试中已过期的启动等待、选角流程、敌人数量、增援波次和主动退出假设；保留房满、四人地图/战斗/救援/换层/通关检查。新增单浏览器双隔离玩家故障实测，资源检查保证最多两个真实浏览器且串行运行。更新使用说明及本任务人读摘要。
