## 改动

- 新增 Windows `.cmd` 与 macOS `.command` 启动入口，支持中文/空格目录、切换工作目录、参数传递；无 Node.js 时说明安装要求并打开离线游戏。已有 Mac 应用删除固定的个人 Node.js 版本路径。
- SSH 空设备路径改用当前系统值；Windows 打开网页不经过命令解释器，链接参数完整保留，打开浏览器失败不会让服务崩溃；Windows 子进程不额外闪出控制台。
- 修复服务入口判断未解析真实路径造成的静默退出，覆盖 macOS 临时目录别名和链接路径。
- 16 份浏览器测试共用按系统选择的图形参数，自动测试机器使用软件绘图；局域网测试的内存检查支持 Windows/macOS/Linux；两处离线文件网址改用标准转换。统一脚本换行规则，Windows 启动器使用 CRLF。
- 新增原生启动器/服务回归、平台辅助检查和可选画面冒烟；Windows/macOS 自动检查使用最低支持的 Node.js 20，默认执行构建、服务启动和无浏览器的联机检查；渲染冒烟仅在手动勾选 `browser_smoke` 后运行，最终简化为一个浏览器、同时一个页面，只验证离线开局与网页建房。
- README 补双平台入口、Windows 测试安装命令、Node.js/OpenSSH 与防火墙说明；更新摘要和最近五条。
- 用户在本任务中明确要求减轻测试负担；同步调整 AGENTS.md 与 CONTRIBUTING.md，默认最小可行验证，不强制完整画面/四层/长时间联机回归。必要时一个低分辨率浏览器、一项短流程，出现卡顿立即停止。本机检查结束后已确认无本任务浏览器残留。

## 验证

macOS 本机：依赖锁定安装、游戏与主题构建、生成文件一致性、服务语法检查；12 项协作脚本测试、3 项平台辅助测试、浏览器命令/原生启动器/独立服务测试通过。真实服务测试在中文、空格和 `&` 目录运行，验证 HTTP 页面及信息接口。原生启动器用最小测试服务验证入口与传参，不打开额外浏览器。

`python3 work/test_platform_browser.py` 已通过：离线 HTML → WebGL 场景 → 单人选角开局；两独立玩家 → 建房/加入/准备/选角 → 相同地牢种子 → 键盘移动同步，无页面异常。使用临时端口、`--no-wan`、一个浏览器，关闭的仅为本测试服务。平台软件绘图及 Windows/macOS 原生运行结果以本 PR 的 platform 检查为准，配置工作流本身不算测试通过。

软件绘图首次以常规分辨率运行在第二玩家启动时超时；降低测试环境的绘图分辨率后，通过本机软件绘图复验。最终冒烟测试使用游戏现有的 high 画质选项；不把测试分辨率调整当作游戏性能提升。

两平台首轮原生 CI 的构建、启动器和真实后台启动通过；联机轻量测试因 Node.js 20 默认未开放浏览器 WebSocket 全局对象失败。CI 测试命令显式加入 `--experimental-websocket` 后复跑；此参数仅供 Node.js 20 的测试客户端使用，游戏网页和后台启动均不需要。

后续两平台构建与全部 20 项后台/联机轻量测试通过；macOS 第二轮远端完整冒烟通过，Windows 第三轮完整冒烟通过；第三轮 Mac 的第二玩家软件绘图启动超时。依用户要求不再重复重渲染，将最终可选脚本缩减为同时一个页面，保留低分辨率/128 阴影；简化后仅做语法检查，未重新渲染，不冒称最终脚本实玩通过。默认交付检查不要求画面回归。

本机在用户调整要求前已完成断线恢复、真实 P2P/静默失效/双方恢复验证；coop 同步与四人四层 LAN 回归最终均通过，页面/控制台异常为 0。首轮旧脚本出现模式断言及固定 320ms 等待倒地提示失败；改用现有 high 画质、较低绘图分辨率，世界/掉落测试隔离无关战斗伤害，倒地测试等待实际提示显示后复验通过，保留原有地图、掉落、救援和通关断言。此后不再继续本机渲染测试。
